# CloudSuite Memcached Loader

This repository contains a CloudSuite Memcached benchmarking loader with:

- Default Twitter skewed workload
- Sequential dataset access with `-q`
- Synthetic fixed-size workload with `-y` or `-b`
- Optional GET-miss fill with `-R`
- CSV stats logging with `-C`

Full build instructions, workload examples, flag reference, dataset formats, and troubleshooting notes are in: [README.md](src/README.md)
